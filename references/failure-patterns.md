# 失败改编病例库

## 使用方法

先判断问题处于语言、呈现、场景、情节还是商业结构层。优先解决最高层问题；结构未成立时，不以润色掩盖问题。每识别一种坏法，同时选择替代机制。

| 失败模式 | 深层症状 | 无效表面修法 | 替代机制 |
|---|---|---|---|
| 信息倾倒 | OS、对白或闪回承担履历、前情、设定和作者结论 | 把 OS 原样改成对白或回忆配图 | 让信息成为证据、筹码、误导、威胁和选择 |
| 假戏剧化 | 画面在动，局势不变 | 增加动作、特写和短句 | 明确目标、阻力、策略、转折和结果 |
| 模板压缩 | 事件反复证明预设主题或固定机制 | 换卡牌、换人物、换地点 | 改变选项价值、代价、人物判断和长期因果 |
| 爽点空转 | 主角口头打脸，对手无力，利益不变 | 增加金句、贴脸和暧昧动作 | 夺回资源、身份、关系或行动权并承担后果 |
| 被动观赏 | 主角只负责可爱、受苦或被照顾 | 增加 OS 吐槽 | 让主角用独特能力作选择并制造下一轮剧情 |
| 强钩子后刹车 | 开场大事件后连续解释、昏迷、组队和准备 | 用未来高潮做倒叙开头 | 尽快进入承诺中的主线，让准备也有冲突和代价 |
| 奖励流水账 | 学习、抽奖、升级、赚钱顺次发生 | 提高奖励数字或配角震惊 | 给能力限制、不确定性、个人判断和收益反噬 |
| 顺风顺水 | 工具、伙伴、买家和答案恰好出现 | 安排低智恶霸压价 | 让资源有条件，让主角亲自解决渠道与风险 |
| 设定教学 | 系统与主角问答讲完规则 | 加吐槽和界面动画 | 只在人物急需使用、违反或误判规则时揭示 |
| 重复冲突 | 多集反复争同一件事、换说法表达同一立场 | 切成更短台词 | 每轮增加事实、筹码、风险、策略或决定 |
| 假危险 | 危险最终无害且无后果 | 延长惊吓、加紧张音效 | 即使误会也造成损失、关系变化或更深问题 |
| 表情型卡点 | 配角震惊、主角宣言、镜头定格 | 加更多惊叹台词 | 卡在未完成行动、迫近危险、困难选择或认知翻转 |
| 反派降智 | 对手只递话、压价、挑衅，方便主角赢 | 加大反派嗓门和恶意 | 给对手合理目标、有效筹码、局部正确与反击能力 |
| 作者代言人 | 系统、灵宠或配角不断点评主题和画面 | 写得更毒舌、更神秘 | 赋予独立欲望、限制、秘密与可能冲突的立场 |
| 旁人认证 | 群众、网友和配角替观众夸可爱、帅、强 | 增加弹幕和惊呼 | 通过行动结果让观众自行判断 |
| 价格替代价值 | 金额、等级和属性增长被当成剧情 | 增加更大数字 | 让资源改变选择、关系、敌人和未来责任 |
| 闪回举证 | 闪回只证明主角说得对或重复台词 | 缩短闪回 | 让闪回补充、反驳、颠覆或埋下新证据 |
| 台词同声 | 所有人都像同一网络写手 | 随机分配口头禅 | 建立人物声纹、身份差异和情绪失控变化 |
| 情绪互拆 | 复仇、暧昧、搞笑相互打断 | 每种元素都保留一点 | 确定场景主情绪，其他元素只作增益或延后 |
| 重复线索 | 多条线索只确认已知答案 | 增加更多证人和档案 | 新线索应增加风险、矛盾、歧义或改变问题 |
| 伪复杂 | 时间线、谜题和术语很多，但人物目标不清 | 再加解释或图解 | 让每层复杂性改变选择，给观众稳定的情感锚点 |
| 字数硬控 | 把常见篇幅误当成质量或时长标准 | 强制每集达到固定字数，低于就补、高于就删 | 以可演过程与目标时长复检；字数只提示异常 |
| 对白撑时长 | 人物反复问答、解释、确认同一结论 | 把句子切短、增加金句或换人复述 | 将信息改成验证、操作、试错、阻拦和带后果的选择 |
| 无效动作注水 | 走路、对视、握拳、空镜很多，但信息和局势不变 | 增加动作段落或情绪形容词 | 让动作暴露信息、改变筹码、制造风险或完成关系变化 |
| 能力代办剧情 | 系统、灵宠或外挂识破谎言、指出答案、替主角找规则漏洞 | 给外挂加俏皮话或限制使用次数 | 让外挂提供受限资源或制造难题，关键判断和解法属于主角 |
| 规则沉积 | 每次反馈只追加一条要求，新旧标准重复或冲突 | 再增加优先级说明，保留全部旧句 | 判定替换、修正、限定或补充；合并成唯一规则并删除失效表述 |
| 过度纠偏 | 为修复内容过薄而堆对白，发现对白拖沓后又堆动作 | 把最新反馈绝对化 | 同时做原问题与反向问题测试，以更高层目标约束两端 |

## 快速删改测试

- 删除这场后，后续几乎不变吗？若是，检查其独特功能。
- 关闭 OS 后，画面已经表达全部信息吗？若是，优先删除。
- 把金额、等级和惊叹台词删掉后，胜利还成立吗？若否，补足行动结果。
- 对手不降智时，主角的方法仍有效吗？若否，重构策略。
- 同一机制第三次出现时，观众还能不知道结果吗？若否，改变代价与变量。
- 解决本集问题后，故事是否恢复原状？若是，增加不可逆变化或长线影响。
